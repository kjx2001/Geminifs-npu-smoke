Ubuntu 安装界面对应填写：

Ubuntu 安装字段	使用上面哪一项
Subnet	子网 Subnet，例如 10.26.42.0/24
Address	IPv4 地址，例如 10.26.42.228
Gateway	默认网关 Gateway
Name servers	DNS 服务器
Search domains	DNS 搜索域，没有则留空

特别注意：

Address 填服务器地址，例如 10.26.42.228。
Subnet 填网络地址，例如 10.26.42.0/24。
不要把两者填反。
如果地址配置方式显示 auto，当前可能是 DHCP。
如果显示 manual，当前是静态 IP。

六、查看每个容器的启动参数、挂载和自动重启策略

直接整段执行：

for c in $(sudo docker ps -aq); do
    echo
    echo "================================================"
    sudo docker inspect -f \
'容器名称={{.Name}}
镜像={{.Config.Image}}
重启策略={{.HostConfig.RestartPolicy.Name}}
网络模式={{.HostConfig.NetworkMode}}
运行时={{.HostConfig.Runtime}}
特权模式={{.HostConfig.Privileged}}' "$c"

    echo "端口映射："
    sudo docker port "$c" 2>/dev/null || true

    echo "目录和 Volume 挂载："
    sudo docker inspect -f \
'{{range .Mounts}}  类型={{.Type}}  源={{.Source}}  容器内={{.Destination}}
{{end}}' "$c"

    echo "设备映射："
    sudo docker inspect -f \
'{{json .HostConfig.Devices}}' "$c"
done

这里最重要的是：

重启策略
端口映射
源目录
容器内目录
设备映射
运行时
是否 privileged
